# RapfiWeb → RapfiDroid 역이식 계획

> 작성 2026-10-11 · 기준: RapfiWeb `fd529b4`(ui: max board, text-only labels) · 대상: RapfiDroid `main`

RapfiWeb 은 이 앱을 웹으로 옮긴 것이다. 옮기는 동안 웹에서 디자인을 다시 다듬었고(`.calm-design/DESIGN.md`),
기능도 몇 가지 늘었다. 이 문서는 그 차이를 앱으로 되돌리는 계획이다. **앱만 가진 기능(원격 엔진 · 도구 ·
스왑2 · 시계 · 규칙 선택 · 데스크톱 설정 전 항목)은 지우지 않는다** — 접어 두거나 메뉴 뒤로 보낼 뿐이다.

## 0. 원칙 (웹 DESIGN.md 에서 그대로)

1. **판이 주인공.** 판 위아래에 조작 줄을 두지 않는다. 휴대폰 세로는 판(가장자리까지) → 이동 바 → 탭 → 카드.
2. **1초 안에 둔다.** 앱을 열면 엔진이 뒤에서 뜬다. 누르면 돌이 놓이고, ▶ 를 누르면 엔진이 읽는다.
3. **필요할 때만 펼친다.** 엔진 수치 · 시간 · 후보 수 · 파일 형식 · DB 옵션은 접힌 펼침(Disclosure) 뒤.
4. 카드마다 채운 버튼은 하나. 값이 없으면 «없음» 타일 대신 한 줄 안내. 카드는 흰 면 + 머리카락 테두리, 그림자 없음.
5. 화면 글은 «무엇을 하는지»만. 왜 그런지는 펼침 안. 한 카드의 안내는 한 줄. 영문 대문자 지표(DEPTH · EVAL) 대신 «깊이 · 평가».

## 1. 차이 목록

| 영역 | 웹 | 앱(지금) | 할 일 |
|---|---|---|---|
| 셸 | 하단 6탭(보드 · 연구 · 정석 · DB · 엔진 · 설정), 한 줄 상단 바 + 엔진 칩 + 테마 단추 | 5탭(정석 없음), 화면마다 부제 | 6탭 · 부제 제거 · 상단 바에 엔진 칩(상태 낱말, 켜기/다시 시도) · 테마 단추 |
| 엔진 기동 | 앱이 뜨면 자동 | 엔진 탭에서 «연결»을 눌러야 | 마지막 대상(기본 기기 엔진)으로 자동 연결, 설정에서 끔 |

## 3. 하지 않는 것

- 웹이 뺀 기능을 앱에서 빼지 않는다(시계 · 스왑2 · Soosorv · 규칙 선택 · 원격 엔진 · 도구 · 사용자 툴바).
- RenjuNet 파생물은 여전히 기기 밖으로 나가지 않는다. 새 팩도 앱 전용 저장소에만 있다.
- 웹의 `.rif` «아무 화면에 끌어다 놓기»는 안드로이드에 없는 동작이라 «파일 열기 인텐트 + 화면의 파일 고르기»로 대신한다.

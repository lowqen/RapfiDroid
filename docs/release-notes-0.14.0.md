**첫 공개 릴리스입니다.** 오목·렌주 판에 **Rapfi 엔진이 기기 안에서** 돌아갑니다 —
서버도, 인터넷도 필요 없습니다.

### 설치

`RapfiDroid-0.14.0.apk` 를 내려받아 실행하세요. 「출처를 알 수 없는 앱」 설치를
한 번 허용해야 합니다. Android 8.0(API 26) 이상, **arm64 기기 전용**입니다.

업데이트 알림을 받으려면 [Obtainium](https://github.com/ImranR98/Obtainium) 에
`https://github.com/lowqen/RapfiDroid` 을 추가하면 새 릴리스마다 알려 줍니다.

### 들어 있는 것

- **기기 내 엔진** — Rapfi(arm64-v8a, NEON). 대국·분석·금수 판정·PV·평가바가
  비행기 모드에서도 그대로 동작합니다. 신경망 가중치 4종(프리스타일·표준·
  렌주 흑/백)이 동봉돼 있어 첫 실행에 추가로 받을 것이 없습니다.
- **기기 DB** — 엔진이 배운 국면이 `rapfi.db` 로 기기에 남고, 다음에 켤 때
  이어집니다. 앱을 끌 때 `YXSAVEDATABASE` 를 먼저 보내 저장을 마칩니다.
- **오프닝 익스플로러** — 1~4수 이름 249개, 흑 5수 유불리 11등급(모양 1,889개),
  환원 목록.
- **랭킹** — 26주형과 5수 모양.
- **게임 리뷰·기보 입출력·국면 증명·수순 탐색기**, PC Yixin-Board 설정 67개.
- **서버 모드**는 그대로 있습니다 — 고급 설정에서 켜면 원격 Rapfi 에 붙어
  대용량 DB·장시간 심층 분석을 씁니다. 기본값은 기기 내 엔진입니다.

### 실전 통계를 채우려면 (선택)

익스플로러의 실전 승률과 랭킹의 대국 수는 **RenjuNet 대국 DB** 가 있어야 채워집니다.
그 자료는 라이선스가 재배포를 금지하므로 앱에 넣을 수도, 어딘가에서 받아 오게 할
수도 없습니다. 대신 **앱이 기기 안에서 직접 만듭니다**:

> 설정 ▸ **대국 데이터 추가** → renju.net 에서 XML(`.rif`) 내려받기 → 그 파일 고르기 → 만들기

한 번 만들면 기기에 남습니다. 만든 자료는 앱 밖으로 나가지 않습니다.

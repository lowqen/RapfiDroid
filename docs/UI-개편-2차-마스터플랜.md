# UI 개편 2차 마스터플랜 — Mornye 화면을 기준으로

> **읽는 법.** 2026-10-29 에 세운 계획서다. 1차(`UI-개편-마스터플랜.md`, P0 ~ P5)는 Mornye 의 **코드**를
> 보고 구조를 옮겼다. 2차는 사용자가 직접 찍어 준 Mornye **화면 6장**을 기준으로, 보이는 모습을 가능한 한
> 그대로 옮긴다. **승인 전에는 앱 코드를 고치지 않는다.** 맨 끝 「결정 필요」가 Phase M1 전에 답이 있어야
> 하는 것들이다.
>
> **경계는 1차와 같다.** 엔진 통신 · 탭 좌표 · 백그라운드 서비스 · ViewModel 로직 · `drawBoard`(판 그림)
> · `TagPalette`(값의 색) · RapfiWeb 과 공유하는 색 램프 값은 손대지 않는다. 판 위는 «색은 값이다».
>
> **라이선스.** Mornye 는 GPL-3.0 이다. 코드는 옮기지 않고, 화면의 모양 · 치수 · 색의 관계를 보고 새로 만든다.

## 0. 화면에서 잰 것

스크린샷은 923 px 폭 = 약 411dp(1dp ≈ 2.25 px). 색은 픽셀을 직접 찍었다.

| 화면 | 보이는 것 | 잰 값 |
|---|---|---|
| 디자인(②③) | 큰 제목 «디자인» · 원형 뒤로 버튼 · 파란 섹션 머리 · 연결 그룹 · 미리보기 카드 · 아이콘 버튼 그룹 | 페이지 `#FDFBFE`, 그룹 행 `#F1F1F3`(페이지보다 **어둡다**, 테두리 **없음**), 행 사이 틈 ~3dp, 바깥 모서리 ~28dp, 행 높이 ~64dp(부제 있으면 ~78dp), 섹션 머리 `#4E5C72` 15sp 굵게, 체크 원 · 스위치 트랙 `#4C5D8B`, 미리보기 배경 `#E2E3E8` 위 흐린 라벤더 원 `#DDDEEF` |
| 설정(④) | 큰 제목 · 알약 검색창 · 프로필 카드 · 아이콘+제목+부제+꺾쇠 행 · 미니 플레이어 · 하단 바 | 검색 알약 56dp `#E8E7EF` 테두리 없음, 아바타 원 `#CFDEF9`, 진행 막대 `#4B6192` + % 를 파란 글씨, 하단 바 `#F2F2F4`, 선택 알약 `#DEE4F9` + 굵은 라벨, 선택 아이콘은 **채운** 모양 · 나머지는 **외곽선** 모양 |
| 레포(⑤) | 아이콘 칩 줄(가로 스크롤) · 항목 카드: 아이콘 타일 · 제목 · 버전 배지 · 두 줄 설명 · 알약 버튼 | 선택 칩 `#E3E8FE`(채움, 테두리 없음), 나머지 칩은 외곽선, 버전 배지 `#F0F1F6` 알약, «설치» 채운 알약 `#49588C`, «설치됨» 외곽선 + 체크(비활성) |
| 재생(⑥) | 가운데 제목 · 큰 굵은 곡명 · **물결 진행선** · 품질 알약 · 표현형 버튼 그룹 | 재생 버튼 ≈100×72dp 둥근 사각 `#266388`, 이전/다음 ≈68×72dp 연한 둥근 사각, 셔플/반복은 맨 끝의 맨 아이콘, 가사: 지금 줄은 진하고 굵게 · 나머지는 흐리게 |
| 대기열(⑦) | 어두운 스크림 위 시트 · 작품 색으로 물든 시트 · 손잡이 · 머리 줄 + 아이콘 · 꽉 찬 연한 알약 버튼 · 강조 행 | 시트 `#F3E5DC`(작품의 복숭아빛), 알약 `#F1DCBF`, 강조 행 `#F7E1C9` + 제목은 진한 갈색, 시트 윗 모서리 ~33dp, 손잡이 32×4dp |

**한 줄로:** Mornye 는 ① 흰 페이지 위에 **한 톤 어두운 무테 면**을 깔고, ② 강조는 **채도 낮은 한 색**의
**연한 톤**(선택 알약 · 칩 · 아바타)과 **진한 톤**(스위치 · 채운 버튼) 두 가지로만 쓰고, ③ 글자는 **크고 굵은
제목**과 **보통 무게의 본문**으로 크게 대비시키고, ④ 주인공(앨범 · 곡)의 색을 그 화면의 면에 물들인다.

## 1. 지금 앱과의 차이(같은 눈으로 본 것)

| 항목 | Mornye | 지금 앱 | 효과 |
|---|---|---|---|

| 행 | 앞 아이콘 · 제목 18 ~ 20sp · 부제 · 꺾쇠, 높이 64 ~ 78dp | 아이콘 없음, 제목 15sp | 손이 가는 크기 · 훑어보기 |
| 단일 선택 | 행 끝 채운 체크 원 / 아이콘 버튼 그룹 | 체크 칩 줄 | |
| 하단 바 | 선택은 채운 아이콘 + 굵은 라벨, 나머지 외곽선 아이콘 | 모두 채운 아이콘 | |

| 진행 | 물결선 | 직선 | |

| 지속 상태 | 다른 탭에서도 보이는 미니 플레이어 | 다른 탭에선 분석 상태가 안 보임 | |

## 2. 단계별 계획

각 Phase 는 1차와 같은 방식: 컴포넌트 → 골든 기록 · 눈으로 확인 → 대비 시험 → CI 녹색 → 실기 확인.

### M1. 면과 색 — «흰 페이지 위 무테 면»(③④⑤ 의 바탕)

| 대상 | 바꾸는 것 |
|---|---|
| 중성 램프 | 따뜻한 회색(hue 74) → 강조색(298°) 쪽으로 아주 살짝 차가운 회색(채도 0.004 ~ 0.006). 기존 «배경화면 색조» 기능이 이미 이 길로 hue 를 바꾸므로 기본 hue 만 바꾸면 된다 |
| 역할 배정 | 페이지 = `surface`(톤 99, `#FDFBFE` 근처), 카드 · 그룹 행 = `surfaceContainerLow`(톤 95 근처, `#F1F1F3`), 검색 알약 · 배지 = `surfaceContainerHigh`(톤 92 근처) — 카드가 페이지보다 **어둡게** |
| 카드 | 테두리 · 림 · 그라데이션 **제거** → 단색 무테 면. 그라데이션은 «주인공 면»(M5 의 보드 무대, M3 의 미리보기)에만 |
| 강조 두 톤 | 연한 톤 = `secondaryContainer`(선택 알약 · 칩 · 아이콘 타일 · 아바타), 진한 톤 = `primary`(스위치 · 채운 버튼 · 체크 원) — 지금 Violet/Lilac 그대로, 쓰는 자리만 Mornye 처럼 |
| 다크 · AMOLED | 같은 관계를 어둡게: 페이지 톤 10, 면 톤 17 · 22. AMOLED 는 페이지 0 · 면 7 그대로 |
| 시험 | 새 역할 쌍 AA, 면과 페이지가 구분되는지(≥ 1.06:1, 테두리가 없으니 이것이 경계), 강조 · 의미색 거리 그대로 |

시각 변화: 설정 · 정석 · 연구가 «종이 위 흰 카드»에서 «흰 화면 위 회색 면»으로. 오밀조밀함의 가장 큰 원인(테두리)이 사라진다.

### M2. 글자와 머리 — 큰 제목, 강조색 섹션 머리(②③④⑤)

| 대상 | 바꾸는 것 |
|---|---|
| 페이지 제목 | 목록 화면(설정 · DB · 정석 목록 · 연구 각 탭 목록) 맨 위에 **34sp ExtraBold** 왼쪽 정렬, 위 여백 ~56dp. 스크롤하면 지금의 52dp 바로 접힘(설정 · DB 의 접히는 머리를 일반화). 판이 있는 화면은 1차 결정대로 한 줄 머리 유지 |
| 섹션 머리 | `ConnectedGroup` 제목을 강조색(진한 톤) 15sp SemiBold, 들여쓰기 20dp |
| 행 글자 | 제목 18sp(본문 위 단계), 부제 15sp 회색. 행 최소 높이 64dp |
| 글꼴 | Pretendard 그대로(한글). 제목만 ExtraBold(800) — Mornye 의 둥근 굵은 제목 느낌을 무게로 |

### M3. 설정을 «목록 → 하위 화면»으로(③④ 를 그대로)

| 대상 | 바꾸는 것 |
|---|---|
| 설정 첫 화면 | 큰 제목 · 알약 검색창(56dp, 무테) · **아이콘 + 제목 + 부제 + 꺾쇠** 행: 디자인(테마 · 색 · 진동), 엔진(스레드 · 해시 · 서버), 대국 · 표시, 데이터(RenjuNet · DB), 고급 사용자 모드, 정보 |
| 하위 화면 | 원형 뒤로 버튼(48dp, `surfaceContainerHigh`) + 큰 제목 + 섹션 머리 + 연결 그룹. 앱 안 내비게이션(뒤로 = 설정 첫 화면) |
| 디자인 화면 | ③ 을 그대로: 맨 위에 **미리보기 카드**(흐린 강조색 원 두세 개가 깔린 배경 위에 작은 판 + 툴바 미리보기, 오른쪽 아래 «밝은/어두운» 배지), «테마» 는 **아이콘 버튼 그룹**(시스템 · 밝은 · 어두운, 선택은 진한 톤 채움), 검은 배경 · 배경화면 색조 · 진동은 스위치 행 |
| 단일 선택 | 칩 대신 «행 끝 채운 체크 원»(언어 · 스레드 수처럼 항목이 적은 것은 행으로) — 많은 것(시간 프리셋)은 칩 유지 |
| 스위치 | 엄지에 체크 아이콘(Material 1.4 의 `thumbContent` 로 가능) |
| 검색 | 하위 화면 항목까지 검색해서 바로 그 행으로(현재 검색 기능을 하위 화면 구조에 맞게) |

### M4. 목록 · 칩 · 카드 부품(⑤)

| 부품 | 모양 | 쓸 곳 |
|---|---|---|
| 아이콘 칩 줄 | 가로 스크롤, 선택 = 연한 톤 채움 · 무테, 나머지 = 외곽선, 앞 아이콘 | 랭킹 필터, 오프닝 탐색 필터, 리뷰 대상 |
| 항목 카드 | 앞 **둥근 사각 아이콘 타일**(활성 = 연한 강조, 비활성 = 회색), 제목 18sp, 오른쪽 **배지 알약**, 두 줄 설명(말줄임), 아래 알약 버튼(채움 / 외곽선 + 체크 비활성) | 정석 강좌(진도 배지 · 이어서 / 완료), 내 정석, 리뷰 대기열, 랭킹 행 |
| 배지 | `surfaceContainerHigh` 알약 12sp | 버전 · 판 수 · 수 수 |
| 채운 알약 버튼 | 높이 48dp, 진한 톤 | 주 행동 하나(카드마다 하나 — 1차 규칙 유지) |
| 진행 막대 | 둥근 끝 + 오른쪽에 강조색 % | 팩 빌드, 리뷰, 정석 진도 |

### M5. 보드 화면을 «재생 화면»처럼(⑥⑦)

| 대상 | 바꾸는 것 |
|---|---|
| 툴바 | ⑥ 의 버튼 그룹 그대로: 가운데 **▶ 둥근 사각 ≈96×64dp 채움**(진한 톤), 양옆 **‹ › 둥근 사각 ≈64×64dp 연한 톤**, 맨 끝 `|<` `>|` 는 맨 아이콘, 새 판 · 진영 전환은 더 바깥 맨 아이콘(셔플 · 반복 자리). 알약 배경 없음. 누르면 모서리가 살짝 각지는 **모양 모핑**(스프링). 스크럽은 그대로 |
| 요약 줄 | 최선수를 크게(28sp 굵게, ⑥ 의 곡명처럼), 승률 · 평가 · 깊이는 그 아래 **품질 알약** 하나(`승률 71% · 평가 120 · 깊이 18/27`, ⑥ 의 «FLAC · 16-bit») |
| 진행 | 시간 제한 분석일 때 경과를 **물결선**(정지 그림 — 물결이 흐르는 애니메이션은 엔진이 도는 동안 CPU 를 쓰므로 안 함). Material 1.4 에 없어서 Canvas 로 직접 |
| 시트 | ⑦ 처럼 **판의 나무색으로 물든 면**(라이트: 크림, 다크: 짙은 나무 그늘 — 값이 아닌 재질색이라 «색은 값이다»와 충돌 없음), 윗 모서리 32dp, 손잡이 32×4, 머리 줄(«분석» + 아이콘 행동), 꽉 찬 연한 알약 행동 하나 |
| 후보 수순 | ⑥ 의 가사처럼: 미리보기 중인 줄은 진하고 굵게, 나머지는 흐리게 |
| 미니 분석 바 | ④ 의 미니 플레이어: 분석 · 대국이 진행 중일 때 **다른 탭에서** 하단 바 위에 얇은 바(미니 판 썸네일 · 최선수 · 승률 · 둥근 사각 ⏸). 누르면 보드로. 위 가장자리에 진행 물결선 |
| 무대 배경 | 판 뒤 페이지에 아주 흐린 나무색 · 강조색 원(③ 의 미리보기 배경 방식). 판 자체는 그대로 |

### M6. 내비게이션 · 크롬(④)

| 대상 | 바꾸는 것 |
|---|---|
| 하단 바 | 선택 = **채운 아이콘 + 굵은 라벨 + 연한 톤 알약**, 나머지 = **외곽선 아이콘**(Material Icons Outlined). 바 면 = `surfaceContainer` |
| 레일 | 같은 규칙 |
| 엔진 칩 | 무테 연한 알약(지금의 외곽선 알약 → 면) |
| 뒤로 버튼 | 하위 화면 · 레슨 페이지: 원형 채움 |
| 대화상자 | 큰 모서리(28dp) · 무테 면, 버튼은 알약 |

### M7. 마감 — 모양 모핑 · 다크 · 실기

- 누를 때 모양 모핑: 채운 버튼 · 툴바 버튼 · 체크 원(Material 3 Expressive 의 눌림 모양, 스프링 · 감속 모드면 없음).
- 다크 · AMOLED 화면 골든 추가, 글꼴 1.3 · 2.0, TalkBack(아이콘 버튼 그룹 · 체크 원의 역할 · 선택 상태).
- A16 실기: 분석 중 NPS(미니 분석 바 · 물결선이 엔진을 느리게 하지 않는지), 스크롤 · 시트 프레임.

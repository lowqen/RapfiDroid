# 첫 실행 안내(온보딩) 계획 — Mornye 의 처음 설정 · 둘러보기를 기준으로

> **읽는 법.** 2026-10-31 에 세운 계획서다. 사용자가 찍어 준 Mornye 첫 실행 화면 10장(중복 2장 → 실제 8장)을
> 기준으로, **처음 설정(5단계)** 과 **둘러보기(6쪽)** 를 Zenyth 에 맞는 내용으로 옮긴다.
> **승인 전에는 앱 코드를 고치지 않는다.** 맨 끝 「결정 필요」가 O1 전에 답이 있어야 하는 것들이다.
>
> **경계는 UI 개편 1 · 2차와 같다.** 엔진 통신 · 판 그림(`drawBoard`) · 값의 색(`TagPalette`) · 설정 키와
> `settings.txt` 행은 손대지 않는다. 온보딩은 이미 있는 저장값(언어 · 테마 · 알림 권한 · 팩 빌드)을
> **처음 한 번 묻는 창구**일 뿐, 새 설정을 만들지 않는다.
>
> **라이선스.** Mornye 는 GPL-3.0 이다. 코드는 옮기지 않고, 화면의 모양 · 치수 · 색의 관계를 보고 새로 만든다.
> 색은 Mornye 의 슬레이트 블루가 아니라 이 앱의 토큰(`primary` · `secondaryContainer` · `surfaceContainer*`)을
> 쓴다 — 2차 M1 에서 정한 «쓰는 자리만 Mornye 처럼».

## 개정 — 2026-10-31: 11화면 → 2화면 (이 절이 1장 · 3장보다 우선한다)

O2 착수 전 검토(사용자 제기: 온보딩 단계가 늘수록 이탈이 는다)로 첫 실행을 **최대 2화면**으로 줄였다.
근거로 든 수치(UserGuiding · Digia 블로그의 «4~5단계 40~60% 이탈»)는 가입 폼이 있는 흐름의 업체 자료라
그대로 옮길 수는 없지만, 결론은 같다 — 판을 보기 전에 11화면은 많고, 대부분 그 자리에 있을 이유가 없었다.

| 원래 | 개정 | 이유 |
|---|---|---|
| ① 환영 | **1/2 환영** — 앱 마크 · «Zenyth에 오신 것을 환영합니다» · 한 줄 소개 · **기능 행 3**(둘러보기 1쪽을 합침) | |
| ② 언어 | 화면 없음 → 환영 화면 왼쪽 위 **«🌐 한국어 ⌄» 알약**, 누르면 언어 목록 시트 | 대부분 폰 언어가 맞다 |
| ③ 화면 모드 | 뺌 | 이미 기기를 따르고, 모든 머리에 전환 버튼이 있다 |
| ④ 알림 | **2/2 알림** — 그대로(설명 → 시스템 창 → 체크 카드), 마지막이라 FAB 는 «✓ 시작하기» | 기능상 필요한 유일한 단계 |
| ⑤ 기보 데이터 | 뺌 | 익스플로러 · 랭킹의 «대국 데이터 추가» 카드가 필요한 자리에 이미 있다 |
| 둘러보기 6쪽 | 자동으로 띄우지 않음 → **4쪽**(보드 · 연구 · 정석 · 엔진), 설정 ▸ 정보 ▸ «둘러보기»에서 | |

- Android 12 이하: 알림 단계가 없으므로 **환영 1화면**, 링도 숨김.
- 2/2 의 «건너뛰기»는 마지막 단계라 곧 «시작하기»다.
- 단계 계획: **O2** = 위 2화면, **O3** = 둘러보기 4쪽 + 설정 ▸ 정보 진입, O4 · O5 는 그대로(문구 · 검증).

## 1. Zenyth 에 맞춘 내용

### 1.1 처음 설정 — 5단계(Android 13 이상 기준)

Mornye 의 «다운로드 알림 → 저장 폴더» 흐름은 이 앱의 «엔진 · 팩 빌드 알림 → RenjuNet 기보 파일» 과
역할이 똑같다. 그래서 순서도 그대로 둔다.

| # | 제목(ko / en / zh) | 히어로 | 내용 · 행동 | 저장되는 곳(이미 있음) |
|---|---|---|---|---|
| 1 | **Zenyth** | `ZenythMark` 96dp(원 없이) | «폰 안에서 도는 진짜 오목 · 렌주 엔진» / «A real gomoku & renju engine, on your phone» / «在手机里运行的真正五子棋 · 连珠引擎» | — |
| 2 | 언어 선택 / Language / 语言 | `Translate` | 설명 «앱에서 쓸 언어를 고르세요. 나중에 설정에서 바꿀 수 있습니다». 목록: **기기 설정** · 한국어 · English · 中文, 선택 행 = 연한 알약 + 체크 원 | `LocaleManager.applicationLocales` (설정 ▸ 언어와 같은 곳) |
| 3 | 화면 모드 / Appearance / 外观 | `Palette` | «밝게, 어둡게, 또는 기기를 따릅니다». 설정 ▸ 디자인의 `ThemeButtons`(시스템 · 밝은 · 어두운) 그대로 — 고르는 즉시 온보딩 화면이 바뀐다 | `themeFollowsSystem` + `settings.txt` 27행 |
| 4 | 알림 켜기 / Notifications / 通知 | `Notifications` | «엔진이 백그라운드에서 분석하는 동안 알림에 상태가 보이고, 기보 데이터를 만드는 진행도 알림으로 볼 수 있습니다». 연한 알약 «알림 켜기» + «건너뛰기». 허용 → 체크 카드 «알림이 켜졌습니다!» | 시스템 권한 `POST_NOTIFICATIONS` |
| 5 | 실전 기보 데이터 / Game data / 实战棋谱 | `PostAdd` | «renju.net 에서 받은 기보 파일(.rif)을 고르면 오프닝 익스플로러 · 랭킹의 실전 통계를 폰 안에서 만듭니다. 몇 분 걸리고, 나중에 해도 됩니다». 연한 알약 «기보 파일 선택» + 글자 버튼 «renju.net 열기». 고르면 진행 카드(물결 진행선 + «알림에서도 볼 수 있어요»), 끝나면 체크 카드 | `PackBuildManager` (설정 ▸ 데이터와 같은 것) |

- **5단계는 선택이다.** FAB «시작하기»는 처음부터 켜져 있고, 빌드가 돌고 있어도 누를 수 있다(빌드는
  `PackBuildService` 가 이어 간다). Mornye 처럼 폴더를 «반드시» 고르게 하지 않는 이유: RenjuNet 파일은 사용자가
  브라우저에서 따로 받아야 하고, 라이선스상 앱이 대신 받아 줄 수 없다.
- **4단계의 «다음»은 Mornye 처럼 허용 또는 건너뛰기 전까지 꺼져 있다.** «건너뛰기»는 바로 5단계로 넘어간다.
  두 번 거부해 시스템이 더 묻지 않는 상태면 버튼이 «설정에서 켜기»로 바뀌어 앱 알림 설정
  (`ACTION_APP_NOTIFICATION_SETTINGS`)을 열고, 돌아오면(`ON_RESUME`) 다시 확인해 체크 카드로 바꾼다.
- **Android 12 이하**(minSdk 26): 앱별 언어 API(`LocaleManager`)가 없고 알림 권한도 필요 없다. 두 단계를
  **목록에서 뺀다** → 1 · 3 · 5 의 3단계, 링은 `n/3`. (결정 O-A)
- 지금 `MainActivity.onCreate` 가 앱을 열자마자 알림 권한을 묻는다(`maybeRequestNotifications`). 이걸 **4단계로
  옮긴다** — 설명 없이 뜨는 시스템 창이 첫 화면이던 것을 없앤다.

### 1.3 언제 보이나

| 경우 | 처음 설정 | 둘러보기 |
|---|---|---|
| 새로 설치 | 보인다 | 처음 설정 끝나면 바로 |
| 업데이트(이미 쓰던 사람) | **안 보인다** | **안 보인다**, 대신 그 버전의 «새로워진 점»에 «설정 ▸ 정보 ▸ 둘러보기» 한 줄 |
| 설정 ▸ 정보 ▸ «둘러보기» | — | 언제든 다시 |
| 처음 설정 도중 앱 종료 | 다음 실행에 **그 단계부터** | |
| 둘러보기 도중 종료 | | 다음 실행엔 안 보임(건너뛴 것으로 침 — 앱을 막지 않는다) |

- 새 설치 판정은 `WhatsNew.freshInstall` 과 같은 방법(`firstInstallTime == lastUpdateTime`) — 하나로 뽑아 같이 쓴다.
- «새로워진 점»은 새 설치엔 원래 안 뜨므로 온보딩과 겹치지 않는다. 그래도 게이트가 온보딩 중엔 `WhatsNewOnUpdate` 를
  그리지 않게 해 둔다.

## 2. 구조

### 2.1 게이트 — 처음 설정은 앱 «앞», 둘러보기는 앱 «위»

```
MainActivity.setContent
└─ ZenythTheme
   └─ OnboardingGate
      ├─ stage == Setup → SetupScreen            (ZenythRoot 를 아직 만들지 않음)
      └─ else           → ZenythRoot + WhatsNewOnUpdate
                          └─ stage == Tour → TourScreen 을 전체 화면 층으로 덮음
```

- **처음 설정 동안엔 `ZenythRoot` 를 만들지 않는다** → `ShellViewModel.init` 의 엔진 자동 시작이 돌지 않는다. 엔진
  알림이 4단계 설명보다 먼저 뜨는 일, 신경망 로딩이 온보딩 애니메이션과 CPU 를 다투는 일을 없앤다.
- **둘러보기는 `ZenythRoot` 위를 덮는다** → 사용자가 읽는 몇십 초 동안 엔진이 뒤에서 뜬다. 둘러보기를 닫으면
  엔진이 이미 준비돼 있다. 덮는 층은 뒤 화면 입력을 막고, 시스템 바 inset 을 자기가 받는다.

### 2.2 저장

`UiPrefs` 에 int 하나: `onboarding.done` = 마친 온보딩 판(`ONBOARDING_VERSION = 1`).
나중에 처음 설정에 꼭 물어야 할 단계가 생기면 판을 올리고 «그 단계만» 보여 줄 수 있게 남겨 둔다. 처음 설정의
진행 단계는 `onboarding.step`(int)에 저장 — 언어를 바꾸면 액티비티가 다시 만들어지고, 도중에 앱을 닫을 수도 있다.

`Setup → Tour → Done` 을 정하는 건 순수 함수 `OnboardingStage.of(done, step, freshInstall)` — 테스트 대상.

## 4. 결정 — 2026-10-31 확정(전부 권장안)

추가 결정 **O-G**: «새로워진 점» 창은 처음 설정 · 둘러보기가 **모두 끝난 뒤에** 뜬다(사용자 요청). 디자인은 «예시와 비슷하거나 더 예쁘게».

| ID | 질문 | 권장 |
|---|---|---|
| O-A | Android 12 이하에서 언어 · 알림 단계 | **뺀다(3단계).** 12 이하에서 앱별 언어를 하려면 AppCompat 을 새로 들여야 하고, 알림 권한은 원래 필요 없다 |

| O-C | 「고급 사용자 모드」를 처음 설정에서 물을지 | **묻지 않는다.** 둘러보기 6쪽에서 알려 주기만 |
| O-D | 기존 사용자(업데이트)에게 | **안 보여 준다.** «새로워진 점»에 다시 보는 길만 알린다 |
| O-E | 4단계 «다음»을 허용/건너뛰기 전까지 끌지 | **끈다(Mornye 그대로).** 단 «건너뛰기»가 바로 넘어가므로 막히는 일은 없다 |
| O-F | 엔진 자동 시작을 처음 설정이 끝날 때까지 미룰지 | **미룬다.** 둘러보기 동안엔 뒤에서 뜨게 해서 기다림은 그대로 숨긴다 |

|---|---|

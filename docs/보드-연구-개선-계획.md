# 연구 탭 데이터 유도 · 형세 그래프 · 국면 카드 개선 계획

> **읽는 법.** 2026-10-31 에 세운 계획서다. 사용자 요청 세 가지:
> ① 연구 탭의 오프닝 · 수순 · 랭킹에서 대국 데이터가 없으면 «거의 반드시» 추가하게 이끌 것,
> ② 보드의 형세 그래프가 초라하니 다시 그릴 것,
> ③ 국면 카드의 «기보» 메뉴를 일반 사용자가 찾을 수 있게 하되 깔끔함은 지킬 것 — 그리고 카드에서 «둘 차례 · 수 · 마지막»을 뺄 것.
> **승인 전에는 앱 코드를 고치지 않는다.** 맨 끝 「결정 필요」가 착수 전에 답이 있어야 하는 것들이다.
>
> **경계.** 엔진 통신 · 판 그림(`drawBoard`) · 값의 색(`TagPalette`) · 설정 키는 손대지 않는다. RenjuNet 라이선스상
> 앱은 데이터를 받지도 싣지도 않는다 — 유도는 «사용자가 받은 파일을 고르게» 하는 데까지다.

## 0. 지금 모습

| 곳 | 지금 | 문제 |
|---|---|---|
| 연구 ▸ 오프닝 | 헤더 카드 **아래**에 작은 `DataSetupCard`: 한 줄 설명 + «대국 데이터 추가» 버튼 → 단계 3개짜리 대화상자 | 작고 목록 중간이라 지나치기 쉽다. 무엇이 생기는지(빈도 · 승률 · 실제 기보)가 한 줄로만 적혀 있다 |
| 연구 ▸ 랭킹 | 같은 작은 카드가 탭 위에. 데이터가 없으면 각 주형 카드의 실전 칸(승률 막대 등)이 **아무 설명 없이 빠진다** | 빈 이유를 알 수 없다 |
| 연구 ▸ 수순 | 아무것도 없음 | 수순 탐색은 **대국 데이터를 쓰지 않는다**(보드의 돌로만 계산). 여기서 큰 카드를 띄우면 «넣으면 수순이 달라진다»는 오해를 준다 |
| 형세 그래프 | 분석 탭 시트의 엔진 카드 아래, 96dp 높이. 흑 승률 선 + **모든 수에 점** + 0까지 연한 채움 + 0 · 50 · 100% 가로선, 현재 수에 원 하나 | 50% 기준이 약해 누가 유리한지 한눈에 안 보인다. 점이 많으면 지저분하다. 축 · 수 번호 · 변화량이 없다. 눌러도 아무 일 없다 |
| 국면 카드 | 제목 줄 오른쪽 끝의 작은 글자 «기보 ⌄» → 드롭다운(열기 · .psq 저장 · .sav 저장 · 링크 복사 · 국면 문자열 · 이미지 저장). 그 아래 «둘 차례 · 수 · 마지막» 3칸, 주형 · 평가 · DB · 주석 · 기보 이름 | «기보»가 제목 옆 장식처럼 보여 메뉴라는 걸 모른다. 3칸은 보드 · 한 줄 요약 · 시트 머리와 겹친다 |

## 1. 계획

### 1.1 연구 탭 — 대국 데이터 유도

**새 부품 `DataHeroCard`** (`feature/data/`) — 온보딩과 같은 문법(원 아이콘 → 큰 제목 → 설명 → 기능 행 → 행동)으로, 대화상자 없이 카드 안에서 끝낸다.

| 부분 | 내용 |
|---|---|
| 머리 | 96dp 원 안의 아이콘(`QueryStats`) · 제목 «실전 대국 데이터를 추가하세요» · 한 줄 «RenjuNet 의 실제 대국 기록으로, 폰 안에서 만듭니다» |
| 무엇이 생기나 | 기능 행 3줄(아이콘 타일 + 굵은 이름 + 설명): **오프닝** 다음 수마다 실전 빈도 · 승률 / **랭킹** 26주형 실전 승률 · 5수 모양 빈도 / **기보** 이 국면을 지난 실제 대국을 보드에 올리기 |
| 단계 | 번호 3칸을 가로로: ① renju.net 에서 받기(«열기» → 브라우저) ② 받은 파일 고르기 ③ 폰이 몇 분 동안 만듦 |
| 행동 | 꽉 찬 **채움 알약** «파일 고르기» (바로 파일 선택기), 그 아래 글자 버튼 «renju.net 열기» |
| 만드는 중 | 같은 자리가 물결 진행선 + 단계 이름 + «앱을 나가도 계속되고 알림에서 볼 수 있습니다», «중지» |
| 끝남 | 체크 카드 «데이터가 준비됐습니다 · 대국 N판»이 잠깐 보이고 카드가 접히며 통계가 채워진다 |

**탭별 배치**

| 탭 | 배치 |
|---|---|
| 오프닝 | 목록 **맨 위**(헤더 카드보다 먼저)에 `DataHeroCard`. 데이터 없이도 되는 것(주형 이름 · 흑 5수 유불리 · 환원)은 그 아래 그대로 |
| 랭킹 | 탭 위 작은 카드를 `DataHeroCard`로. 주형 카드마다 빠져 있던 실전 칸 자리에 회색 빈 막대 + «대국 데이터를 넣으면 표시» 한 줄 — 왜 비었는지 그 자리에서 알게 |
| 수순 | 데이터와 무관하므로 **얇은 배너 한 줄**(아이콘 + «오프닝 · 랭킹의 실전 통계가 꺼져 있습니다» + «추가» 글자 버튼 → 오프닝 탭의 큰 카드로 이동)(결정 D1) |

**한 번 더 권하기**(결정 D2 · D3)

- 데이터 없이 오프닝 · 랭킹을 **처음** 열 때 아래에서 시트가 한 번 올라온다: 같은 내용을 짧게 + «지금 추가» / «나중에». 설치당 한 번(`UiPrefs`).
- 큰 카드의 «나중에»를 누르면 큰 카드가 **얇은 배너**로 접히고(수순과 같은 모양), 배너를 누르면 다시 펼쳐진다. 데이터가 생기면 둘 다 사라진다.

### 1.2 형세 그래프 — 다시 그리기

| 항목 | 새 모양 |
|---|---|
| 머리 줄 | 제목 «형세» + 오른쪽에 **큰 값** «흑 63%»(22sp 굵게, 지금 수의 값) + 그 옆 직전 수 대비 변화 «▲ 8%p»(흑 유리면 흑돌색 · 백 유리면 회색 알약) |
| 면 | **50% 선을 중심으로 위아래 두 색 면**: 곡선이 50% 위면 그 사이를 흑돌 색(판 스킨의 흑), 아래면 백돌 색(백 + 머리카락 외곽선)으로 채운다 — 누가 얼마나 유리했는지 면적으로 읽힌다 |
| 곡선 | 부드러운 단조 3차 곡선 2.5dp, **점 없음**. 읽지 않은 구간은 끊고 회색 점선으로 잇는다. 메이트는 위 · 아래 끝에 붙인다 |
| 기준선 · 축 | 50% 선은 조금 진하게, 25 · 75%는 아주 옅게. 왼쪽 위 · 아래에 작은 «흑» «백», 아래에 10수마다 수 번호 |
| 큰 변화 | 직전 대비 ±15%p 이상 바뀐 수에 작은 점(형세가 기운 곳). 리뷰 등급이 있으면 그 수는 등급 색 점(실수 · 악수) |
| 지금 수 | 세로 커서선 + 원 마커(판의 마지막 수 링과 같은 색) |
| 손으로 | **탭하거나 가로로 끌면 그 수로 이동**(`GameRepository.jumpTo`), 수 경계마다 툴바 스크럽과 같은 햅틱, 끄는 동안 커서 위에 «23수 · 흑 58%» 말풍선(결정 D4). 리뷰 · 증명 중이나 대국 탭에선 기존 잠금 규칙을 그대로 따른다 |
| 크기 | 높이 96 → **140dp**(가로 화면 120dp) |
| 다크 · AMOLED · 접근성 | 돌 색은 판 스킨에서 가져와 테마를 따른다. TalkBack «형세 그래프, 23수, 흑 58%», 좌우 조정 동작으로 수 이동 |
| 성능 | 곡선 · 면 Path 는 기록이 바뀔 때만 다시 만든다. 분석 중 갱신 빈도는 지금과 같다 |

자리는 지금처럼 분석 탭 시트의 엔진 카드 아래(결정 D5).

### 1.3 국면 카드 — 기보 메뉴 드러내기, 3칸 삭제

| 바꾸는 것 | 내용 |
|---|---|
| 삭제 | «둘 차례 · 수 · 마지막» 3칸. 좁은 화면 맨 위의 한 줄 요약(«백 차례 7수 · K5 포월»)은 **남긴다**(결정 D6) |
| 제목 줄 | «국면 · 렌주»만. 오른쪽의 «기보 ⌄» 제거 |
| 기보 묶음 | 카드 맨 아래에 Mornye 의 **아이콘 버튼 묶음**(설정 ▸ 디자인의 테마 버튼과 같은 모양): 같은 폭 4칸, 칸마다 아이콘 + 짧은 라벨, 연한 면 · 높이 64dp — **열기 · 저장 · 공유 · 이미지**(결정 D7) |
| 두 번째 선택 | **저장**을 누르면 작은 메뉴로 .psq / .sav, **공유**는 링크 복사 / 국면 문자열. 이렇게 하면 처음 보이는 칸은 넷뿐이라 깔끔하고, 모든 기능이 한 번 누르면 보인다 |
| 대국 탭 | 같은 묶음, 그 아래 «기권 · 무승부» 그대로 |
| 비어 있을 때 | 첫 국면처럼 주형 · DB 줄이 없으면 카드는 제목 + 기보 묶음뿐 — 빈 줄을 만들지 않는다 |

## 2. 단계

각 단계: 컴포넌트 → CI 골든 기록 · 눈으로 확인 → 다듬기 → CI 녹색 → 실기 확인(지금까지와 같은 방식).

| 단계 | 내용 | 시험 |
|---|---|---|
| **R1. 국면 카드** | 3칸 삭제, 기보 묶음 + 두 메뉴 | 골든 `analysis_cards` 갱신 · 대국 탭 카드 · 첫 국면(빈 카드) |
| **R2. 데이터 유도** | `DataHeroCard` · 오프닝 · 랭킹 배치 · 랭킹 빈 칸 안내 · 수순 배너 · 한 번 시트 · 접기 | 골든: 큰 카드(대기 · 만드는 중 · 끝남) · 배너 · 랭킹 빈 칸. 단위: 시트는 한 번만, 데이터 생기면 사라짐 |
| **R3. 형세 그래프** | 두 색 면 · 곡선 · 머리 값 · 축 · 큰 변화 점 · 커서 · 탭/끌기 이동 | 골든: 흑 우세 · 역전 · 빈 구간 · 메이트 · 다크. 단위: 좌표 → 수 번호, 큰 변화 판정 |
| **R4. 실기** | 폰에서 세 가지 모두 | 체크리스트(계획서에 추가) |

## 3. 결정 필요(착수 전)

| ID | 질문 | 권장 |
|---|---|---|
| D1 | 수순 탭에도 큰 카드를 띄울지 | **얇은 배너만.** 수순은 데이터를 쓰지 않아 큰 카드는 오해를 준다 |
| D2 | 데이터 없이 오프닝 · 랭킹을 처음 열 때 한 번 시트로 권할지 | **넣는다**(설치당 한 번). «거의 반드시»에 가장 가까운, 그러나 한 번뿐인 방법 |
| D3 | 큰 카드를 «나중에»로 얇은 배너까지 접게 할지 | **허용.** 매번 큰 카드가 화면 절반을 차지하면 데이터를 안 넣기로 한 사람에게 벌이 된다 |
| D4 | 그래프를 탭/끌어서 수 이동 | **넣는다.** 그래프가 «보는 것»에서 «쓰는 것»이 된다 |
| D5 | 그래프 자리 | **지금 자리(엔진 카드 아래).** 시트 머리(최선수 · 승률)와 겹치지 않게 |
| D6 | 좁은 화면 한 줄 요약(차례 · 수 · 마지막 수)도 지울지 | **남긴다.** 지우라고 한 것은 국면 카드의 3칸이고, 한 줄 요약은 좁은 화면에서 그 카드를 대신하는 별개의 줄이다 |
| D7 | 기보 묶음 구성 | **열기 · 저장 · 공유 · 이미지 4칸**, 형식 선택은 저장 · 공유 안의 작은 메뉴로 |

## 4. 위험

| 위험 | 대응 |
|---|---|
| 큰 카드 · 시트가 «광고처럼» 느껴짐 | 시트는 설치당 한 번, 카드는 «나중에»로 접힘, 데이터가 생기면 흔적 없이 사라짐 |
| RenjuNet 라이선스 | 앱은 여전히 받지 않는다. «renju.net 열기»는 브라우저로 사이트를 여는 것뿐 — 지금의 대화상자와 같다 |
| 그래프 끌기가 시트 스크롤 · 판 스크럽과 겹침 | 가로 끌기만 그래프가 가진다(세로는 시트 스크롤로 넘김). 툴바 스크럽과 같은 햅틱 규칙 |
| 흑돌 색 면이 다크 판에서 안 보임 | 판 스킨의 흑 · 백 값을 쓰고 면 투명도를 테마별로 정해 골든으로 확인 |
| 국면 카드가 짧아져 좁은 화면 시트 배치가 바뀜 | 골든 `screen_board_sheet` 로 확인 |
